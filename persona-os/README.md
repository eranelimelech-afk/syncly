# PersonaOS

חדר בקרה לניהול דמות דיגיטלית — תכנון פרסומים, שער QA לפני כל פרסום,
ניתוח ביצועים והמלצות המשך. אינסטגרם ופאנביו.

## התקנה

```bash
npm install
npm run dev
```

## עשרת המסכים

| מסך | מה הוא עושה |
|---|---|
| ביבליה | ה־Character Bible הנעולה. מקור האמת לכל השאר |
| גיליון זהות | כיסוי ספריית הרפרנסים — 8 זוויות חובה |
| מרכז בקרה | KPI, מה דורש החלטה, משפך אינסטגרם ← פאנביו |
| שער אישורים | 22 בדיקות, ציון 0–100, 5 חוסמים קשיחים |
| מעבדת ניסויים | השערה, משתנה אחד, מדד הכרעה, הצעת תיקון לביבליה |
| המלצות המשך | 7 הפוסטים הבאים, מחושבים ממכסה × ביצועים × צינון סמלים |
| תבניות פרומפט | פרומפטים שנבנים מהביבליה אוטומטית |
| לוח פרסום | משבצת שלא אושרה נשארת ריקה |
| ביצועים | טבלת פוסטים, מיון לפי כל מדד |
| מה עובד | ניתוח lift לכל ערך בשבעה ממדים |
